# ADR-0010: 动态黑板状态镜像投影与受控对等会话生命周期

## 背景

在多智能体协同及多会话自主协作场景中，系统显现两类架构阻抗：

1. **黑板感知阻抗**：
   公共黑板遵循拉取模型，单播调用为严格对等通信。在缺乏被动感知能力时，协作者无法得知黑板共享状态变更，只能通过高频调用 `board_list` 进行试探性轮询，耗费工具轮次并拉长时延。若采用静态提示词区块注入，初始化后无法感知动态状态，且修改静态配置会触发提示词全局重编导致前缀缓存击穿。
2. **易逝时间戳击穿前缀缓存**：
   宿主运行时上下文投影采用字符串全等比较决定是否追加历史快照。若动态上下文包含相对时间差或倒计时秒数，自然时间流逝会导致每轮推理比较均不相等，持续生成新快照，击穿大模型服务端键值缓存，增加首字时延与开销。
3. **过期条目长期堆积**：
   会话归档或终结后，其在黑板发布的临时协调条目滞留，干扰后续决策。
4. **对等会话创建能力缺失**：
   既有子代理机制仅支持树状派生，绑定于发起方的执行生命周期，无法建立拥有独立自治循环的同级根会话。

---

## 动因

- **消除盲目工具轮询**：在每步模型决策前通过状态镜像投影感知最新事实，消除冗余查询。
- **保护键值前缀缓存**：通过纯状态幂等表征，确保无实质变更时不追加新快照，最大化命中前缀缓存。
- **自治对等会话编排**：提供受控工具支持创建独立同级根会话并完成异步任务派发。
- **限制系统故障半径**：建立工作区配额、频率限制、代际深度熔断与标题防伪校验。
- **级联自愈状态治理**：事件驱动结合惰性探测，在会话生命周期结束时清理临时黑板条目。

---

## 选型

### 镜像选型

- **静态区块频繁覆写**：修改静态区块频繁触发全局配置变更事件，破坏提示词流水线缓存，予以否决。
- **引导智能体高频轮询**：每轮主动调用查询工具，产生额外往返时延与标记消耗，予以否决。
- **动态上下文纯状态投影**：选中方案。利用动态上下文钩子在步进级别求值，去除易逝时间戳保证文本幂等性，兼顾即时性与前缀缓存命中。

### 会话选型

- **扩展子代理工具增加平级模式**：子代理内部深度耦合并发栈与临时存储，破坏既有调用契约，予以否决。
- **通过本地网络端口调用外部接口**：破坏进程内零网络依赖原则，引入端口硬编码与认证脆弱性，予以否决。
- **宿主进程内根实体创建**：选中方案。通过宿主注册表解耦作用域，创建标准独立根会话，实现内存直接调用。

## 决策

### 规范

1. **纯状态幂等与缓存保护**：
   状态镜像投影文本严禁输出易逝时间差或实时时间戳。过期条目在内存求值时静默过滤。仅当黑板发生离散实体增删改或状态迁移时投影文本才改变，保障服务端键值前缀缓存命中率。
2. **严格工作区封装**：
   状态镜像投影严格过滤当前工作区条目；会话创建默认继承创建者的规范化工作区路径，防止越界穿扰。
3. **有限故障半径**：
   单工作区根会话建立硬配额，初始为 10，后由 ADR-0021 收敛为 5 个运行态会话；单会话创建限频每分钟 5 次；衍生代际深度上限为 2，防止递归派生失控。
4. **标题完整与防伪校验**：
   会话标题强制过滤特权伪造前缀，禁止重名，未提供时自初始指令提取并规范化。
5. **双轨级联清理**：
   结合生命周期事件监听与惰性自愈探针，实现分级清理：软归档、物理抹除与交付物留存。
6. **异步点火立即返回**：
   完成对等会话创建与首条指令挂载后，通过异步推进启动执行，立即返回会话元数据，严禁同步阻塞等待对端执行。

### 契约

#### 镜像契约

- **注册钩子**：`ctx.systemPrompt.context`，排序权重 130，紧随代理委托之后作为环境事实层。
- **容量与预算**：当前工作区未归档条目最多 3 至 5 条；单条标题严格截断至 60 字符；总长度硬上限 800 字符。无条目时输出空字符串，不产生额外标记开销。

#### 创建契约

- **工具名称**：`session_create`。
- **输入参数**：
  - `title`：同级会话标题，过滤特权伪造前缀；
  - `initial_message`：可选初始任务指令，提供时异步投递启动；
  - `context_post_ids`：关联黑板条目标识数组；
  - `model`：可选覆写模型标识；
  - `reasoning_effort`：可选推理强度；
  - `preset`：可选挂载预设标识；
  - `workspace`：可选指定工作区，缺省继承调用方工作区。
- **返回值**：包含 `sessionId`、`title`、`workspace`、`status`、`generation` 结构化字段。

## 收益

### 收益
- **消除盲目轮询**：每轮执行前即可读取当前环境事实，大幅降低查询工具调用频次；
- **保护推理缓存**：纯状态幂等投影杜绝多余快照生成，保证大模型服务端键值缓存高命中率；
- **丰富协作拓扑**：补充树状代理体系，支持在同一工程工作区内编排运行自治对等会话；
- **状态及时清理**：协同会话终结后自动回收临时黑板条目，避免噪声堆积。

### 权衡
- **配额管理约束**：根会话受到单工作区并发配额约束，会话达成目标后应及时归档以释放槽位。

---

## 验证

- **状态镜像幂等性测试**：在黑板无变动时，断言连续多次步进生成的上下文投影文本完全相同，不触发新消息快照；
- **工作区隔离断言**：验证多工作区环境下，状态镜像投影与会话创建不泄露无关工程路径与条目；
- **并发与代际防线断言**：配额超限时断言拦截并返回错误结构，拦截非法代际递归；
- **级联清理验证**：会话归档后断言其关联临时条目退出活跃索引，成果条目妥善标记保留。
