# ADR-0014: Canvas Gutter Routing, Lineage Focus, and Scoped Theme Parity

- **Status**: Accepted
- **Date**: 2026-09-10
- **Deciders**: Architect, Frontend Lead, Core Maintainers
- **Informed**: All Web Users, Multi-Session Operators

> **路由演进**：
> 同列会话调用的早期单侧统一走线几何模型已被 [ADR-0019](./0019-channel-split-routing-and-lineage-on-demand-focus.md) 演进替代。同列向下的单播调用采用右出右进，同列向上的单播调用采用左出左进，彻底消除列中轴与卡片碰撞。

---

## 背景

### 痛点
协作看板在多会话并发与黑板协同场景中暴露出视觉缺陷：
1. 连线穿透会话卡片文字：黑板归属边直接以二次贝塞尔曲线连接会话顶部与黑板底部。在同一工作区分组列内，下层会话的连线直接纵向穿透上方所有中间会话卡片与文字；跨会话调用边在同列跨层相连时亦存在类似文字穿越；
2. 全量连线导致视觉噪点：所有静态黑板归属线与历史调用线全量常态高亮绘制，缺乏主次层级，造成视觉噪点与信息杂乱；
3. 单向暗色锁定与切换入口缺失：画布样式全量硬编码深色色值，宿主在浅色主题下看板出现白底嵌黑块的失调，同时看板顶栏缺少直观的明暗切换快捷按钮；
4. 宿主对话宽度手柄穿透看板视口：宿主外壳在会话激活时无条件挂载用于调整聊天转录宽度的宽度手柄。由于宿主未与激活视图做条件绑定，手柄直接穿透并悬浮于全屏拓扑画布之上，在用户移动鼠标或拖动画布时引发光标突变及拖拽手势被意外截获。

---

## 决策

### 通道走线
1. 端口进出规范：调用发起端或黑板发布端统一由节点右侧引出；调用接收端统一由节点左侧接入；
2. 专属走线通道：在工作区分组列左右外侧预留走线通道。连线出节点后直接进入外侧通道，在通道内纵向穿行避开所有中间会话节点，到达目标高度后横向折入，严禁穿透任何会话卡片；
3. 黑板发布走线：由发布会话右侧引出进入右侧通道，纵向直达工作区顶部外边缘后，斜向接入顶部黑板对应条目底部中点；
4. 跨工作区反向走线：右侧工作区调用左侧工作区时，连线自发起节点右侧引出后进入右走线通道平滑折返，通过列间空隙向左横穿并接入目标节点左侧。

### 链路聚焦
1. 默认低噪呈现：依据视觉对比度与看板可读性要求，静态黑板发布归属线默认保持低噪呈现，采用 0.50 细虚线；已落定调用线淡化至 0.30 低对比度；未落定调用连线保持动态流动发光；
2. 按需链路点亮：当鼠标悬停或点击选中某一会话或黑板条目时，高亮激活与其直接相关的关联链路，呈现 1.00 实线与脉冲发光。

### 主题适配
1. 宿主接口映射：看板工具栏右侧增加明暗模式切换按钮，深色模式显示日间图标，浅色模式显示夜间图标。按钮点击映射宿主主题切换服务；
2. 严格作用域隔离：深色与浅色样式全部收敛在画布容器及其子类选择器内，基于宿主暗色根属性与语义变量自适应渲染，严禁向插件作用域外注入全局样式。

### 布局几何
1. 工作区列起始与头部尺寸：工作区列纵向起始点固定为 150px；列头部胶囊包围盒位于相对坐标 (12, 10)，高度为 38px，其底边画布坐标为 198px；
2. 严格 16px 头间距不变量：遵循 16px 留白规约，工作区头部底边与首个会话卡片顶边之间必须保持严格的 16px 正向净间距，首卡片顶边画布坐标固定为 214px；
3. 会话节点垂直坐标推导：会话卡片垂直半轴为 26px，行间距步长为 72px。首个会话节点垂直中心固定为起始基准叠加 90px，第 i 个节点的垂直中心为首节点中心累加 i 乘以 72px。严禁将首节点中心硬编码为穿透头部的数值。

### 视口隔离
1. 声明式自愈隐藏：遵循纯 CSS 声明式零污染准则，当看板容器挂载时，通过包含伪类匹配将宿主宽度手柄平滑抑制；
2. 生命周期零外溢：该抑制与画布容器实例生命周期强绑定。切入看板时宽度手柄自动隐形且不再响应指针事件；切回对话视图时伴随容器卸载即刻自愈恢复，绝不污染宿主全局或篡改外部状态。

---

## 收益

### 收益
- 消除连线穿越会话卡片文字的问题，拓扑走线规整清晰；
- 常态降低非聚焦连线视觉干扰，交互时突出关联链路；
- 完整支持浅色与深色主题切换，且严格遵守宿主插件边界与零污染原则；
- 消除宿主对话宽度手柄对看板视口的悬浮穿透与拖拽拦截，保障画布平移与缩放体验纯净流畅。

### 权衡
弯折连线计算稍有增加，通过固定通道坐标偏移与平滑三次贝塞尔曲线结合，保持渲染性能。
