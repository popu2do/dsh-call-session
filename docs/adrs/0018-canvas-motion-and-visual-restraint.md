# ADR-0018: Canvas Motion Token, Geometric Invariant, and Visual Restraint Specification

- **Status**: Accepted
- **Date**: 2026-09-17
- **Deciders**: Architect, Frontend Lead, Core Maintainers
- **Consulted**: QA Automation Lead, UX Reviewer
- **Informed**: All DSH Web Users, Canvas Maintainers

---

## 背景

### 痛点
协作看板在动效设计演进中暴露出多项缺陷：
1. 边线几何拉伸畸变：代码将专为节点状态圆点设计的脉冲关键帧错误套用于拓扑连线。由于路径缺乏局部原点且跨越视口，导致整条曲线以画布原点整体伸缩漂移，端点脱离会话卡片；
2. 浅色主题漫射光斑：活跃与聚焦连线沿用深色模式专用的高强度发光滤镜，在浅色底色上形成脏灰色漫射晕轮，严重降低连线与文本可读性，违反克制极简与对比度要求；
3. 实线与流动虚线类名冲突：聚焦高亮链路本应呈现为清晰实线，但流动虚线类名强制覆盖了内联实线属性，造成状态冲突与无效的位移动画；
4. 频繁重绘与掉帧：全量矢量路径叠加大半径发光滤镜并常驻执行循环动画，影响界面流畅度。

---

## 决策

### 几何约束
1. 禁止几何缩放：任何表示拓扑连线的矢量路径元素，严禁在其样式动画或过渡中施加缩放、平移或矩阵变换；
2. 动效属性受限：连线的动态效果严格限定在纯视觉渲染属性，流动指示仅允许改变虚线偏移量，脉冲呼吸仅允许改变透明度、描边透明度或描边宽度微幅呼吸。

### 落点脉冲
落点脉冲以描边透明度过渡呈现，见 ADR-0013。脉冲属性枚举纳入描边透明度，几何不变式与禁止发光投影的约束保持不变。

### 主题对比
1. 浅色模式去发光：在浅色作用域下，边线移除发光阴影，改以高对比度单色实线或深色低对比虚线呈现，消除浅色底色下的晕轮伪影；
2. 深色模式受限发光：深色模式下的阴影模糊半径限制在 3px 以内，透明度限制在 0.45 以下，避免过度发光，保持界面克制。

### 状态解耦
1. 高亮态实线固化：当会话或调用处于悬停或选中高亮状态时，连接线统一切换为实线，停止位移动画，转为专用轻量呼吸样式；
2. 类名解耦互斥：实线脉冲样式与流动虚线样式互斥，防止样式属性冲突。

### 动效减弱
支持用户系统的减弱动态效果配置，在开启时自动停用无限循环流动动画，保留静态连线，保障无障碍体验。

---

## 收益

### 收益
- 消除连线端点脱离卡片位置的几何偏移问题；
- 浅色模式下看板清晰干练，对比度达到标准规范；
- 消除高斯发光导致的持续重绘，稳定保障流畅渲染。

### 权衡
动效视觉表现趋于克制，由数据流动与状态呼吸取代，对齐克制技术文档与界面规范。

---

## 验证

1. 静态特征检查：测试断言脉冲连线类名不包含缩放形变动效；
2. 浅色主题断言：断言浅色作用域下发光滤镜被显式置为空；
3. 端到端测试：全量自动化测试套件执行通过。
