# ADR-0026: Canvas Rounded Rectangle Cards, Toolbar Streamlining, and Dual Lineage Modes

- **Status**: Accepted
- **Date**: 2026-10-08
- **Deciders**: Architect, Frontend Lead, UX Reviewer
- **Consulted**: QA Automation Lead, Core Maintainers
- **Informed**: All DSH Web Users, Canvas Maintainers

---

## 背景

### 现状
ADR-0012 建立了可视化协作看板，ADR-0014 与 ADR-0019 确立了通道分流走线与常态按需显影。但在实际协作演进与长标题场景中，旧版呈现方案暴露出三项人机交互与视觉瓶颈：
1. 几何椭圆空间折损与标题过度截断：会话节点采用几何椭圆，椭圆四角内凹导致可用排版空间折损超过两成，内部文本偏离中轴时宽度急剧收缩，叠加状态徽标挤压导致标题可用宽度仅 62px，长中文标题在数个字内即被省略号强行截断，斜向连线切点在偏角处向内凹陷，破坏了通道布线平直出入秩序；
2. 常态连线抑制导致悬停探索负担：常态历史连线零渲染虽消除了视觉交错噪点，但导致用户在未触发悬停时完全无法感知通信网络全貌，必须逐个节点悬停探索，削弱了看板作为全局拓扑视图的感知效率；
3. 顶栏控制项冗余与信息层级失衡：顶栏保留的放大缩小显式按钮与现代触控板和滚轮连续缩放交互冗余，大段文字统计标签占据主栏视觉焦点，缺乏克制感。

### 约束
- 几何不变式与向后兼容：保持槽位高度 72px、列宽 260px、外接半宽 96px、半高 26px，并保留既有交点接口契约；
- 矢量图元与作用域隔离：全量图标采用工程级矢量图元，严禁表情符号，样式严格收敛于看板作用域；
- 状态持久化：用户偏好的连线呈现模式需跨会话持久化存储在本地存储中；
- 只读非侵入观测：维持看板纯内存、只读、不产生被动唤醒的观测边界。

---

## 动因

- 文本清晰与布局利用率：消除标题过早截断，可用排版宽度由 62px 扩充至 160px 以上；
- 双模连线灵活性：在极简低噪与全景拓扑透视之间提供低认知负荷的单键切换；
- 顶栏密度克制：移除冗余缩放按钮，将指标降级为图标化微型指示簇，释放顶栏留白呼吸空间；
- 平滑法向切点：以圆角矩形外切封闭解保证侧向连线平直出入，消除偏角内凹畸变。

---

## 方案

### 方案一
仅增大椭圆半长轴至 120px。
- 弊端：导致节点宽度超出列宽，压缩通道净空间，无法根除曲率内凹缺陷。

### 方案二
强制常态全量渲染所有连线且不可关闭。
- 弊端：多会话密集调度下退化回蜘蛛网噪点状态。

### 方案三
圆角矩形卡片重构，精简顶栏并引入双模连线切换。
- 收益：兼顾全局拓扑直观性与局部细节可读性，几何与人机交互高度统一。

---

## 决策

采纳方案三：圆角矩形卡片重构、顶栏精简与双模连线切换。

### 规约
1. 卡片尺寸不变量：卡片物理几何严格限定为宽 192px、高 52px、圆角 8px，中心坐标原点为零坐标；
2. 双模连线机制：
   - 隐藏连线模式：未交互时会话调用线、黑板发布线与引用线常态保持零渲染，悬停实体时按需显影关联链路；
   - 显示连线模式：常态下调用连线与黑板归属线细虚线完整绘制，悬停实体时关联链路增强至实线脉冲，非关联链路衰减至低对比度；
3. 顶栏精简：顶栏移除显式缩放控制按钮，统计指标采用纯矢量无表情图元紧随操作按钮组。

---
## 收益

### 收益
- 标题排版宽度扩充至 160px，中文字符完整可见；
- 平直出入端点消除走线内凹畸变；
- 用户可自主决定拓扑信息的呈现密度，消除悬停探索成本；
- 顶栏视觉层级清晰克制，信息干扰降至最低。
