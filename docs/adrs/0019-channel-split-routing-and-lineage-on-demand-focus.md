# ADR-0019: Channel-Split Routing, Lineage On-Demand Focus, and Port Non-Interference Geometry

- **Status**: Accepted
- **Date**: 2026-09-17
- **Deciders**: Architect, Frontend Lead, Core Maintainers
- **Consulted**: QA Automation Lead, UX Reviewer
- **Informed**: All DSH Web Users, Canvas Maintainers

---

## 1. Context and Problem Statement

### 1.1 Background & Geometric Regressions
ADR-0012 建立了可视化协作看板，ADR-0014 规范了外侧走线通道与右出左进进出端口，ADR-0018 约束了连线动效几何不变式。然而随着同工作区内多会话高频单播协作场景的普及，原规范暴露了四项严重的几何与可用性缺陷：
1. **同列垂直调用强制右出左进导致连线交叉**：同一工作区列内节点纵向排列（X 坐标相同）。当节点间发生上下调用时，由于起点强制在右、终点强制在左，连线必须在卡片垂直间隙中横向穿梭。向上与向下调用并存时，连线形成 S 弯与 X 状交叉缠绕，破坏因果流向直觉；
2. **右侧走线通道空间受限**：所有同列调用与黑板归属线集中在右侧通道，控制点与列边界间距不足，容易贴边或越界；
3. **全量常态渲染造成视觉噪点**：已结算历史调用线在常态下全量绘制，即使透明度衰减为 0.30，依然构成明显的视觉噪声；
4. **悬停 Tooltip 遮挡进出端口与卡片**：105px 高的悬停大卡片居中弹出，直接覆盖卡片上下净间隙（20px）及相邻节点文字和进出箭头。

### 1.2 Architectural Forces & Constraints
- **Geometric Non-Crossing Invariant**：同列垂直调用线严禁横穿列中心轴与卡片间隙；
- **Spatial Dimension Decoupling**：跨列水平调用与同列垂直调用的拓扑端口解耦；
- **Strict Scoped Theme & WCAG 2.1 AA**：浅色与深色模式下均保持清晰度与对比度，避免发光模糊；
- **Prompt KV Cache Defense & Read-Only Invariants**：维持只读观测边界，不增加 Agent 工具集与被动唤醒。

---

## 2. Decision Drivers

- **Driver 1 (Causal Flow Legibility)**：垂直调用上下行分离，消除视觉交叉与拓扑混淆；
- **Driver 2 (Noise-Free Default State)**：常态降低显示密度，按需显影，减少界面视觉负担；
- **Driver 3 (Port Non-Interference)**：悬停浮层避免遮挡拓扑端点、箭头与相邻卡片；
- **Driver 4 (Concentric Channel Tiering)**：多跨层跳数采用同心嵌套分层，走线完全收敛在列边框内。

---

## 3. Considered Options

### Option 1: 仅微调三次贝塞尔曲线控制点（维持全量右出左进）
- **Description**: 维持右出左进几何端口不变，仅加大水平控制点平滑度。
- **Pros**: 改动极小。
- **Cons**: 无法解决起点在右、终点在左的物理拓扑矛盾，只要端点不动，中间必然交叉，治标不治本。

### Option 2: 正交顶底端口（上下进出）
- **Description**: 同列调用统一由卡片顶部和底部引出连接。
- **Pros**: 相邻节点连线为垂直直线。
- **Cons**: 跨层非相邻调用（如节点 1 调用节点 4）仍需穿越中间节点或在外侧大角度弯折，容易穿越卡片文字且方向识别度低。

### Option 3 (Chosen): 上下行双通道分流走线 + 按需显影降噪 + 轻量胶囊浮层
- **Description**:
  1. **同列分流走线**：向下单播右出右进（右侧通道），向上单播左出左进（左侧通道），跨越跳数同心嵌套，零横切列中轴；
  2. **跨列右出左进**：跨列水平调用维持右出左进及顶层反向通道；
  3. **黑板外轨隔离**：黑板发布归属线分配在右侧通道专属外轨，常态细虚线弱化；
  4. **按需显影**：常态完全隐藏已结算历史连线，保留卡片徽标计数；悬停聚焦时点亮一度链路；
  5. **单行轻量胶囊**：Tooltip 压缩为 <=28px 单行胶囊并避开出入端口，完整数据交由 420px 侧边抽屉。
- **Pros**: 消除连线交叉与缠绕；常态拓扑清晰有序；浮层无遮挡；坐标收敛在列宽内。
- **Cons**: 需更新同列几何计算算法与相应单元测试。

---

## 4. Decision Outcome

**Chosen Option**: Option 3 — 上下行双通道分流走线 + 按需显影降噪 + 轻量胶囊浮层。

### 4.1 核心几何与交互不变式
1. **Invariant 1 (同列上下行通道分离不变量)**：同列向下调用起点与终点 X 坐标均严格位于列中轴右侧；同列向上调用起点与终点 X 坐标均严格位于列中轴左侧。严禁同列连线横穿列中轴。
2. **Invariant 2 (通道列宽内敛不变量)**：所有同列走线通道控制点与曲线坐标严格约束在 [106px, 126px] 相对偏移内，确保在 260px 列宽内留有至少 4px 净间距。
3. **Invariant 3 (常态历史线零渲染不变量)**：未悬停/未选中实体时，结算历史调用（>15s 或 status === 'settled'）渲染路径数量为 0，仅保留卡片上的指标徽标。
4. **Invariant 4 (浮层轻量无遮挡不变量)**：Tooltip 高度不超过 28px，垂直位置限制在卡片垂直间隙或下方，不得侵入椭圆节点左右端口接触区域。

## 5. Consequences

### 5.1 Positive
- 消除连线交叉，保持垂直调用流向明确；
- 常态下减少网状连线噪声，交互聚焦时呈现关联链路；
- 解决悬停浮层遮挡节点文本与连线端点的交互问题；
- 列宽尺寸与多列布局完全兼容，不影响缩放自适应。

### 5.2 Negative & Mitigations
- 依赖用户通过悬停/点击查看历史连线；由卡片上的徽标计数（呼入/呼出）直观弥补静态连线隐藏的信息差。

1. **同列几何断言**：在 `tests/client.test.mjs` 中断言下行连线 `startX > 170 && endX > 170`，上行连线 `startX < 170 && endX < 170`；

3. **常态隐蔽与聚焦断言**：断言常态下历史连线数量为 0，悬停时激活实线脉冲类名；
4. **Tooltip 样式检查**：断言 `.dsh-canvas-tooltip` 高度与边距符合胶囊规约。
