# ADR-0019: Channel-Split Routing, Lineage On-Demand Focus, and Port Non-Interference Geometry

- **Status**: Accepted
- **Date**: 2026-09-17
- **Deciders**: Architect, Frontend Lead, Core Maintainers
- **Consulted**: QA Automation Lead, UX Reviewer
- **Informed**: All DSH Web Users, Canvas Maintainers

---

## 背景

### 痛点
协作看板在同工作区内多会话高频单播协作场景中暴露出几何与可用性缺陷：
1. 同列垂直调用强制右出左进导致连线交叉：同一工作区分组列内节点纵向排列。当节点间发生上下调用时，由于起点强制在右且终点强制在左，连线必须在卡片垂直间隙中横向穿梭。向上与向下调用并存时，连线形成交叉缠绕，破坏因果流向直觉；
2. 右侧走线通道空间受限：所有同列调用与黑板归属线集中在右侧通道，控制点与列边界间距不足，容易贴边或越界；
3. 全量常态渲染造成视觉噪点：已结算历史调用线在常态下全量绘制，即使透明度衰减为 0.30，依然构成明显的视觉噪声；
4. 悬停提示遮挡端口与卡片：悬停大卡片居中弹出，直接覆盖卡片上下净间隙以及相邻节点文字和进出箭头。

### 约束
- 几何无交叉不变式：同列垂直调用线严禁横穿列中心轴与卡片间隙；
- 空间维度解耦：跨列水平调用与同列垂直调用的拓扑端口解耦；
- 严格作用域主题与对比度：浅色与深色模式下均保持清晰度与对比度，避免发光模糊；
- 提示词缓存防护与只读约束：维持只读观测边界，不增加智能体工具集与被动唤醒。

---

## 动因

- 因果流向可读：垂直调用上下行分离，消除视觉交叉与拓扑混淆；
- 常态无噪呈现：常态降低显示密度，按需显影，减少界面视觉负担；
- 端口互不干扰：悬停浮层避免遮挡拓扑端点、箭头与相邻卡片；
- 同心嵌套分层：多跨层跳数采用同心嵌套分层，走线完全收敛在列边框内。

---

## 方案

### 方案一
维持右出左进几何端口不变，仅微调三次贝塞尔曲线控制点。
- 收益：改动范围小。
- 弊端：无法解决起点在右且终点在左的物理几何矛盾，中间连线交叉无法彻底消除。

### 方案二
同列调用统一由卡片顶部和底部正交引出连接。
- 收益：相邻节点连线呈现为垂直直线。
- 弊端：跨层非相邻调用仍需穿越中间节点或在外侧大角度弯折，易遮挡卡片文本且流向识别度低。

### 方案三
上下行双通道分流走线，配合按需显影降噪与轻量胶囊浮层。
- 收益：向下单播右出右进走右侧通道，向上单播左出左进走左侧通道，零横切列中轴；常态隐藏已结算历史连线，悬停聚焦显影；提示精简为轻量胶囊并避开出入端口。
- 弊端：需更新同列几何计算算法与相应单元测试。

---

## 决策

采纳方案三：上下行双通道分流走线、按需显影降噪与轻量胶囊浮层。

### 不变量
1. 同列上下行通道分离不变量：同列向下调用起点与终点水平坐标均严格位于列中轴右侧；同列向上调用起点与终点水平坐标均严格位于列中轴左侧，严禁同列连线横穿列中轴；
2. 通道列宽内敛不变量：所有同列走线通道控制点与曲线坐标严格约束在 106px 至 126px 相对偏移内，确保在 260px 列宽内留有至少 4px 净间距；
3. 常态历史线零渲染不变量：未悬停或未选中实体时，已结算历史调用连线渲染路径数量为 0，仅保留卡片上的指标徽标；
4. 浮层轻量无遮挡不变量：悬停胶囊高度不超过 28px，垂直位置限制在卡片垂直间隙或下方，不得侵入节点左右端口接触区域。

## 收益

### 收益
- 消除连线交叉，保持垂直调用流向明确；
- 常态下减少网状连线噪声，交互聚焦时呈现关联链路；
- 解决悬停浮层遮挡节点文本与连线端点的交互问题；
- 列宽尺寸与多列布局完全兼容，不影响缩放自适应。

### 权衡
依赖用户通过悬停或点击查看历史连线，由卡片上的呼入与呼出徽标计数直观弥补静态连线隐藏的信息差。

---

## 验证

1. 同列几何断言：测试断言下行连线起点终点位于右侧通道，上行连线起点终点位于左侧通道；
2. 通道内敛断言：断言同列控制点水平坐标全部位于列边界内部；
3. 常态隐蔽与聚焦断言：断言常态下历史连线数量为 0，悬停时激活实线脉冲类名；
4. 样式检查：断言提示组件高度与边距符合轻量胶囊规约。
