# ADR-0024: 深层模块架构重构、浅层查询门面折叠与存储工具解耦

- **Status**: Accepted (Tool adapter evolved by ADR-0027 and ADR-0030)
- **Date**: 2026-09-23
- **Deciders**: Architect, Engineering Team, Core Contributors
- **Consulted**: Canvas Engineers, Telemetry Engineers, Directory Maintainers, QA Reviewers
- **Informed**: All Plugin Users, Downstream Agents, Web Interface Maintainers

> **架构演化**：此处确立的存储引擎 `BoardStore` 与工具适配 `BoardToolsAdapter` 逻辑分离，在 [ADR-0027](./0027-deep-module-workspace-isolation-tools-registry-and-canvas-geometry.md) 中物理抽取至独立模块，并在 [ADR-0030](./0030-direct-tool-binding-to-board-tools-adapter.md) 中实现工具注册层直接绑定。

---

## 背景

随着系统在前端协作看板、进程内单播分发、公共黑板状态存储与多会话调度场景下的演进，系统的模块深度与测试表面显现四个维度的散弹化与职责倒置阻抗：

1. **看板视图单体杂糅**：
   单体前端脚本将贝塞尔通道分流走线算法、视口双向限位居中与缩放钳位算法、落点脉冲动效状态机与视图渲染紧密耦合。纯几何与视口约束无法脱离文档对象模型独立验证，测试不得不依赖脆弱的模式匹配与模拟环境。
2. **会话查询浅层模块中转**：
   独立会话查询文件仅数十行，其接口与内部实现近乎 1:1，本质只是重新导出目录管理内部函数并包裹一层计数统计，调用方与测试在两个文件间反复跳跃，割裂了局部性。
3. **黑板存储引擎与工具执行门面耦合**：
   黑板存储原本设计为纯存储引擎，但直接混入了工具调用参数解包与多语言文案渲染逻辑，职责外溢。
4. **调用记录环形队列倒置依赖业务数据源**：
   调用记录环形缓冲区作为高性能有限内存队列，却在同文件中承载了全景拓扑数据聚合逻辑，反向引入对黑板存储与会话目录的倒置依赖。

---

## 力量

- **深层模块与高杠杆率**：遵循代码设计原则，追求以极简稳定的接口暴露丰富内聚的实现行为，最大化调用方与测试的杠杆率。
- **局部性与接缝纯度**：同一领域的逻辑必须内聚于一处，存储、几何计算与快照观察者各司其职，杜绝倒置依赖。
- **零破坏向后兼容**：既有公共导出符号、工具调用签名与测试用例契约百分之百保持向后兼容。
- **确定性测试表面**：核心数学与拓扑算法具备脱离浏览器环境独立快速回归的确定性测试表面。

---

## 动因

- **解除文档模型测试束缚**：将看板纯数学几何路由与视口限位算法提炼为纯函数，建立原生测试套件。
- **折叠浅层查询门面**：折叠无实质抽象深度的浅层中转模块，消除跨层重导出，将查询与过滤直接内聚于目录模块。
- **解耦存储与工具适配**：将工具执行逻辑解耦为独立适配器，让存储核心回归纯粹的进程内持久化底座。
- **理顺拓扑观察者依赖**：将全景快照数据汇聚重构为协同层的只读观察者，解耦底座环形队列。

---

## 选型

### 方案一
- **维持现状仅修补单测**：零架构改动成本，但几何与视口测试依然脆弱，接口职责持续越界混杂。

### 方案二
- **激进重构破坏既有路径**：直接删除浅层查询文件，破坏外部已有导入路径与测试引用，违背平滑演进原则。

### 方案三
- **深层提炼与兼容重导出**：选中方案。核心逻辑深度内聚，提炼出的模块具备独立纯单元测试，同时保留薄兼容层，全仓既有测试无感过渡。

---

## 决策

### 支柱

提炼四大核心深层模块，各司其职并消除倒置依赖。

### 路由

- 提炼椭圆外切点方程、自环调用顶部出入、同列双通道分流走线、跨列三段复合贝塞尔通道横跨及黑板外轨专属通道为无状态纯计算实现。
- 提炼视口自适应双向内边距、定位取景双向夹紧、水平首列对齐与垂直黑板优先保护算法。
- 设立专属纯计算测试套件，脱离浏览器容器快速回归。

### 目录

- 会话目录原生封装入参规范化、作用域隔离、归档过滤与状态汇总。
- 既有会话查询文件折叠为自会话目录的转发重导出，收口实现逻辑，消除跨文件双重跳转。

### 存储

- 黑板存储引擎聚焦内存结构、容量淘汰、原子防抖落盘与备份恢复。
- 抽离独立工具适配器，承载参数规范化、保留主题拦截、作者工作区上下文解析与多语言文案组装。
- 存储引擎内部持有默认适配器实例，保持既有方法调用签名向后兼容。

### 聚合

- 全景拓扑汇聚实现移入网络路由协作层，作为只读观察者协同消费会话目录、黑板存储与单播调用记录。
- 调用记录环形队列纯化为零业务依赖的内存有限队列，解除反向依赖。

---

## 收益

- **模块深度显著提升**：核心模型接口紧凑，底层封装完备的计算与校验逻辑；
- **测试表面坚固迅速**：纯数学与纯存储模块脱离外部复杂环境，执行速度达毫秒级；
- **零破坏平滑演进**：全仓自动化测试百分之百通过，静态检查与类型检查零报错。
