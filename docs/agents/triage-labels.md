# Triage Labels

Canonical triage roles map 1:1 to GitHub issue label strings in this repository:

| Role / Label | State Meaning |
| :--- | :--- |
| `needs-triage` | Awaiting maintainer evaluation |
| `needs-info` | Waiting on reporter response |
| `ready-for-agent` | Specified and ready for an autonomous agent |
| `ready-for-human` | Requires human judgment or implementation |
| `wontfix` | Out of scope or already implemented; close with rationale |

Category labels: `bug` and `enhancement`. Every triaged issue carries one category label and one state label.
