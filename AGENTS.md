# Agent Guidelines

## Repository Discipline

- **Headings**: Chinese subheadings <= 4 characters (`## 概述`, `## 安装`, `## 验证`).
- **Domain vocabulary**: Use `CONTEXT.md` terms; replace `Avoid` list synonyms with their canonical names.
- **Live verification**: Acceptance requires physical disk artifacts, matching tool return values, and live host state alongside passing unit tests.

## Agent Skills

- **Issue tracker**: Creating, reading, labeling, or closing issues, or running `/wayfinder` operations -> `docs/agents/issue-tracker.md`.
- **Triage labels**: Triaging issues or mapping canonical triage roles to tracker labels -> `docs/agents/triage-labels.md`.
- **Domain docs**: Naming domain concepts, checking architectural invariants, or verifying runtime changes -> `docs/agents/domain.md`.
- **Public surface**: Updating positioning copy, discovery keywords, README first-screen assets, or catalog listings -> `docs/agents/ecosystem-presence.md`.
- **Peer session mention**: Modifying the `@` composer trigger, workspace drill-down, or session filtering -> `docs/agents/peer-session-mention-spec.md`.
